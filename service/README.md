# Worker service

Run `npm install`, `npx tsc --noEmit -p .`, and `npx vitest run` here. Tests use in-memory SQLite and fake fetch; they never contact YouCam. `better-sqlite3` is test-only, pinned to a version with Node 20 prebuilt binaries. Root contracts and dependencies are unchanged.

`wrangler.toml` is a configuration skeleton, not a provisioned deployment. An integrator must bind an existing D1 database as `DB`, apply `migrations/0001.sql` and `migrations/0002.sql`, and supply server secrets separately. `IP_HASH_SECRET` must be a strong random secret, stable across requests; only the trusted Cloudflare `CF-Connecting-IP` header is used. Missing trusted IP or salt fails closed. Do not forward this handler behind a proxy that lets clients forge that header. No credentials or database identifiers are included. The local dev/e2e harness uses Miniflare and never deploys.

`YOUCAM_MODE=mock` selects synthetic fixtures and an isolated mock quota ledger, leaving the live allowance untouched. Multipart metadata may additionally contain `mockFixture` with `success`, `error_no_face`, `error_src_face_too_small`, or `timeout`; this hook is ignored in live mode. Fixtures contain synthetic numbers only, no photographs. `YOUCAM_MODE=live` requires `YOUCAM_API_KEY` and never falls back. `judgeCode` matching server `JUDGE_CODE` chooses the judge pool; matching `DEV_CODE` chooses dev; otherwise public. Leave access codes unset to disable those privileged pools.

D1 stores accounting, salted IP hashes, session-scoped image digests, and job state, never image bytes, image URLs, or scores. Images are held only while uploading. Observations are isolate-local, logically expire 30 minutes after job creation, and are evicted on the next request; garbage collection or isolate restart may remove them sooner. GET after expiry or result loss returns `not_found`. DELETE `/api/analyses/:id` immediately removes in-memory observations and records a durable privacy tombstone. It returns 204 without a body; unknown or already deleted IDs return the uniform `ApiError` 404. Subsequent GET returns 404. In-flight polls cannot expose deleted observations. Accounting rows and reservation semantics remain unchanged. The browser sends DELETE with keepalive on End session, pagehide, expiry, and when replacing a job. Browser shutdown delivery is best-effort; the 30-minute expiry remains the backstop. Accounting persists to protect the budget, including after expiry. Job IDs are random bearer capabilities; do not log or share them.

Poll at ten-second intervals. Pending timeouts retain the provider task ID and reservation; subsequent GET resumes the same task. Definitive provider failure releases units; success commits once. Ambiguous task-submission failures retain a reservation even if no task ID was received. They require manual provider-console reconciliation and must never be automatically released or recreated. Expiring a session does not release uncertain reservations. Two unresolved tasks intentionally stop new live work. Failed attempts count toward the per-IP daily cap. UTC defines the quota day. The three live pools total 990 units (judge 450, public 180, dev 360).

Upload instructions and provider result envelopes are marked `UNCONFIRMED` in `adapters.ts`. Validate against the actual provider schema before enabling live access. No live call has been made. Score direction and provider source-image retention remain unconfirmed. No severity thresholds are used, and the decision engine gives cosmetic category guidance only.

Contract workarounds: reservation IDs are also job IDs because `BudgetGuard` has no job-link method. The frozen adapter has no fixture argument, so the mock-only metadata hook constructs a fixture adapter inside the Worker. The frozen GET route has no session credential; random job IDs provide access. These choices do not modify contracts.

## Local mock flow and e2e

Run `npm install` then `npm run dev` in service; in another terminal run `npm run dev` in web. Vite proxies `/api` to port 8787. The service command bundles the real worker into Miniflare, creates ephemeral local D1, applies both migrations, generates a per-process privacy salt in memory, and blocks outbound fetches. No cloud account or provider credentials are needed.

Run `cd service && npm run test:e2e` for the Miniflare/workerd + local D1 suite. It generates a valid solid-color JPEG in memory, uses the real web API client, waits the real ten-second polling interval, renders through jsdom and the real decision engine, checks severe-symptom escalation without product promotion, and verifies DELETE/GET/second DELETE. Nothing persists after disposal. Local compatibility date is 2026-05-03, the installed runtime maximum; deployment compatibility remains unchanged.
